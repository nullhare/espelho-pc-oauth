Espelho-PC

Espelho-PC é uma ferramenta pessoal de sincronização usada por seu proprietário para manter uma cópia de arquivos locais no Google Drive.

O aplicativo usa somente o escopo drive.file, limitado aos arquivos que o próprio aplicativo cria ou recebe permissão explícita para usar.

O aplicativo não vende, compartilha nem utiliza dados para publicidade.
